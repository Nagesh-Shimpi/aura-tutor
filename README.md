# AI Tutor

An AI-Powered Learning Platform designed to help students learn smarter with personalized tutoring, quiz generation, coding assistance, progress tracking, and interactive learning support.

---

## 🚀 Overview

AI Tutor is a smart educational platform that provides students with an intelligent learning assistant powered by AI.

The platform allows users to:

- Create an account and securely log in
- Chat with an AI Tutor for doubt solving
- Get coding help and explanations
- Generate quizzes instantly using AI
- Track learning progress using progress cards
- Manage personal profiles
- Customize learning experience using themes like Blossom, Creamy, and more

This project is built to make learning interactive, personalized, and accessible for students.

---

## 💡 Problem Statement

Many students face challenges such as:

- Lack of personalized guidance
- Difficulty understanding coding concepts
- Limited access to instant doubt-solving
- Boring traditional learning methods
- No proper progress tracking system

AI Tutor solves these problems by providing a smart AI-powered educational assistant available anytime.

---

## 🎯 Solution

Our platform offers an all-in-one AI learning environment where students can:

- Ask doubts instantly

- Practice with AI-generated quizzes
- Track their performance
- Stay motivated with progress insights
- Use beautiful learning themes for better engagement
